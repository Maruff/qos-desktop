# Security

Report security problems in qos Desktop privately, through GitHub's private
vulnerability reporting:

https://github.com/Maruff/qos-desktop/security/advisories/new

Please do not open a public issue for them. Only the maintainer sees a private
report until a fix is released.

Say what is affected (the qos Desktop app, the `qos-x11` package and its
loader, or release signing), how to reproduce it, and your qos Desktop
version, phone model and Android version.

Problems in qos itself go to https://github.com/Maruff/qos/security/advisories/new

qos Desktop is built from Termux:X11. If a problem is also in upstream
Termux:X11, it is worth reporting to Termux as well: https://termux.dev/security
